study of dictionaries

Theory-
Dictionaries are a built-in, versatile data structure used to store collections of data in key-value pairs.They are highly optimized for fast data retrieval using unique keys, functioning as a hash table behind the scenes.
They allow for rapid, direct data retrieval, counting, and mapping, making them superior to lists for looking up specific values using unique keys.Fast Searching: Storing large datasets where finding specific items must be fast.
